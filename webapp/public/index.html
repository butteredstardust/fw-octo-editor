Weapon XP

Each weapon earns XP by use, which unlocks better vendor parts and improves handling. The target shown for each weapon is its value from a 100% reference save — a sensible per-weapon goal (e.g. GRL02 ≈ 505k, PST02 = 100k). Weapons absent from the reference use a flat 100,000 fallback. Set any weapon's XP manually, or batch-set all visible weapons to 100,000 XP.

Vendors & Faction Trust

Vendor trust is stored as a per-faction FactionScore. The wiki's trust tiers (Untrusted / Neutral / Trusted) are derived from this score by the game. Set a faction's score directly, or use the tier presets. Trader availability flags toggle whether a vendor appears in the Innards.

Repair Bench

The Repair Bench repairs one destroyed weapon at a time. A job runs on a timer (the in-game workbench shows a countdown); you cannot start another repair while one is running. To repair you need a destroyed weapon item and the matching faction IFF chip for that weapon's origin. When the timer reaches zero the item is ready to collect from the bench. This page reads the live repair timer and your on-hand IFF chips, and can complete/collect a finished repair so the bench is free again.
